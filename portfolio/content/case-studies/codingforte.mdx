## Overview
CodingForte is an education platform built under **IBNSULEMAN TECH LTD**. As the **founder**, I manage overall delivery and contribute hands-on as a backend engineer (Django), maintain application security, and run DevOps/hosting operations.

## Problem
Building an EdTech platform requires:
- a stable backend that can evolve fast without breaking learners’ experience
- security-conscious design (safe defaults, least privilege, careful data handling)
- production reliability (deployments, hosting, incident prevention)

## What I Built
### Backend engineering (Django/DRF)
- API design and backend feature implementation
- Data modeling and backend workflows for platform functionality
- Maintainable, scalable patterns for future features

### Application security ownership
- Secure defaults in features (validation, access control, safe handling of user data)
- Vulnerability awareness during development and releases
- Security-driven review mindset before shipping

### DevOps + hosting operations
- Production deployment and hosting maintenance
- Environment configuration, operational checks, and stability monitoring
- Cost-aware operational decisions

## Security & Quality Practices
- Baseline: access control, input validation, safe data handling
- Practical checks before release: “what can go wrong?” + fix early
- Evidence-first: document what was changed and why
