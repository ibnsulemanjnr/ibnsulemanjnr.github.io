## Overview
At Gontrel (a restaurant-focused company in Dublin), I built Python automation that:
- collects restaurant metadata from Google Maps
- fetches TikTok videos reviewing restaurants (for discovery/analysis)

This reduced manual effort and enabled structured, repeatable data gathering.

## Problem
Manual collection of restaurant information and social review content is:
- time-consuming
- inconsistent (different analysts, different formats)
- difficult to scale across many locations

## What I Built
### Google Maps restaurant collector
- Python scripts to gather structured restaurant details
- consistent output format for downstream use

### TikTok review collector
- Python scripts to fetch TikTok review videos associated with restaurants
- enables discovery and enrichment beyond static listings

### Data QA approach
- standard checks for completeness and consistency
- repeatable automation routines to reduce errors
